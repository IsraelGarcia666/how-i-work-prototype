# How I Work – Digital Prototype

This repository contains a digital prototype created for a Laurea University of Applied Sciences Service Design project.

The project is based on the **“How I Work” zine and work-life discussion cards** developed by the Finnish Diverse Learners’ Association (Erilaisten oppijoiden liitto).

## Purpose

The purpose of this prototype is to explore how the existing paper-based material could work in a simple digital format.

The prototype is being used for:

- internal team immersion
- usability testing
- comparing paper and digital formats
- identifying possible improvements
- exploring accessibility and privacy considerations

The digital version follows the existing process:

1. Individual reflection
2. Pair or group discussion
3. Shared findings
4. Agreed actions
5. Immersion feedback

## Prototype features

- One section at a time
- Progress indicator
- Larger writing areas
- Checkboxes
- Mobile-friendly layout
- Pair and group discussion sections
- Shared summary
- Immersion feedback section

## Privacy

This is an early prototype.

The current version does **not send or store responses on a server**. Answers remain only in the active browser session and are removed when the page is refreshed or closed.

This approach is intentional because privacy and GDPR are important considerations in the project.

## Project status

This is **not a finished product** and should not be considered an official digital service of the Finnish Diverse Learners’ Association.

The prototype is being used only for educational purposes, testing and service-design research.
