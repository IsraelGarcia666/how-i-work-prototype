HOW I WORK – DIGITAL PROTOTYPE

Quick start:
1. Extract the ZIP folder.
2. Open the folder in VS Code.
3. Double-click index.html OR right-click index.html in VS Code and choose "Open with Live Server" if you have the Live Server extension.
4. Fill in the prototype and use Next/Back.

Files:
- index.html
- styles.css
- script.js

Privacy:
This prototype does not send answers to a server.
Answers are held only in the current browser tab and disappear when the page is refreshed or closed.
The final "Immersion test notes" page can export only the team-observation notes as a .txt file.

Purpose:
This is a simple prototype for Group 3's internal immersion and usability testing.
It follows the existing "How I Work" reflection material, four pair/group discussion themes, and the shared summary flow.

Important:
This is not a finished product and should not yet be treated as Eoliitto's final digital service.
